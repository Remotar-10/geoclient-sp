# GeoClient SP - Territorial Mastery

## 🗺️ Sistema de Gerenciamento Territorial para São Paulo

### 🎉 Novidades - v2.4

**Sistema Completo de Gestão Territorial**
- 📊 Dashboard com estatísticas em tempo real
- 📝 Histórico de atividades automático
- 📄 Export para PDF, CSV e JSON
- 🔍 Filtros ultra avançados multi-empresa
- 💾 Persistência automática no navegador
- 📥 Import/Export completo de dados

### ✨ Funcionalidades

- **Mapa Interativo**: Visualização geográfica completa de São Paulo
- **Sistema de Cliques Inteligente**:
  - 1 clique = Zoom 3x na cidade (sem marcar)
  - 2 cliques = Marca cidade + dropdown de empresas
  - Botão direito = Remove marcação
- **Hover Tooltips**: Informações detalhadas ao passar o mouse
- **Botão Home**: Volta à visualização inicial
- **Dashboard Avançado**: Estatísticas, gráficos e rankings
- **Histórico**: Registro automático de todas as ações
- **Filtros Múltiplos**: Busca, status, múltiplas empresas
- **Export PDF**: Relatórios profissionais do dashboard

**Importar:**

**Exportar:**
- CSV (cidades + empresas)

### 💾 Persistência de Dados

- Salva cidades marcadas

- Histórico de atividades

### 🔍 Sistema de Busca

- Busca de cidades na navbar
- Autocompletar inteligente

- Design Material 3.0

### 🛠️ Tecnologias

- **Leaflet.js** - Mapas interativos
- **GeoJSON** - Dados geográficos dos 645 municípios
- **Chart.js** - Gráficos do dashboard
- **jsPDF + html2canvas** - Export para PDF
- **Vanilla JavaScript** - Performance nativa
- **CSS Grid/Flexbox** - Layout responsivo
- **LocalStorage API** - Persistência de dados
