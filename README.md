# GeoClient SP - Territorial Mastery

## 🗺️ Sistema de Gerenciamento Territorial para São Paulo

### 🎉 Novidades - v2.0

**Dashboard de Estatísticas em Tempo Real**
- 📊 Total de cidades marcadas
- ✅ Taxa de cobertura de SP
- 🏆 Ranking de empresas
- 🕒 Últimas cidades adicionadas
- 🎨 Gráficos visuais por empresa

### ✨ Funcionalidades

- **Mapa Interativo**: Visualização geográfica de São Paulo
- **Sistema de Cliques**:
  - 1 clique = Zoom 3x + marca cidade
  - 2 cliques = Dropdown de empresas
  - Botão direito = Remove marcação
- **Hover Tooltips**: Informações ao passar o mouse
- **Botão Home**: Volta à visualização inicial
- **Dashboard**: Estatísticas completas em tempo real
- **Dropdown Nativo**: Seleção de empresas estilo HTML select

### 🛠️ Tecnologias

- **Leaflet.js** - Mapas interativos
- **GeoJSON** - Dados geográficos
- **Vanilla JavaScript** - Performance nativa
- **CSS Grid/Flexbox** - Layout responsivo
